# ADR-003: Mesh control plane and autonomous heal

## Status
Accepted — 2026-09-05

## Context
Command Center was a 5s poll over public ingest. Copy Patch never wrote git. core-api had no repository. TrueTurn ingested into Other.

## Decision
- Source for the Worker lives in `voltcore-org/core-api` (staged at `dominiccalandro1991-byte/core-api` until org-create is granted).
- Write routes (`/heal`, `/command`) require HMAC-SHA256 mesh headers. Ingest GET/POST stay public.
- `/heal` generates a structural patch, attests path/size/secret bounds against the fleet allowlist, rate-limits 3/hour/source, and commits to `main` only when `AUTONOMOUS_TRUNK=1`.
- `/remediate` remains the unauthenticated copy-patch fallback.
- TrueTurn is a first-class Global Health group.
- Operator mesh key is sessionStorage only. Never shipped in the Pages repo.

## Rejected
- Unauthenticated trunk commits (the Worker URL is public).
- Auto-commit outside the path allowlist.
- Replacing Pages with a React build (npm CI risk; iOS-first still vanilla).

## Secrets (Cloudflare, not git)
`SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `OPENROUTER_API_KEY`, `MESH_HMAC`, `GITHUB_TOKEN`, `AUTONOMOUS_TRUNK`.
